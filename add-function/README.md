# 리시안셔스 현황판 - 정리본

원본 `index(1).html`의 콘텐츠와 기능을 유지하는 것을 우선으로 한 구조 정리본입니다.

- `index.html`: 화면 구조
- `style.css`: 스타일, 반응형, 다크모드
- `script-1.js`: 일정·투표·콜라보·앨범 등 주요 동작과 데이터
- `script-2.js`: 앨범 및 판매처 이미지 데이터와 추가 렌더링
- `assets/`: HTML에 포함되어 있던 이미지 파일

## 사용 방법
폴더의 모든 파일을 그대로 GitHub 저장소에 업로드하세요.
Cloudflare Pages에서 같은 디렉터리 구조로 배포하면 됩니다.
이미지 파일 경로가 바뀌므로 index.html만 단독 업로드하면 이미지가 보이지 않습니다.

## 주의
기능 삭제나 디자인 변경 없이 안전한 파일 분리를 우선했습니다.
실제 브라우저의 모든 상호작용을 자동 테스트한 것은 아니므로
배포 전 탭 이동, 검색, 이미지 팝업, 수량 계산, 다크모드를 확인하세요.
